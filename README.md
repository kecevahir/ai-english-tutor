# AI English Tutor

Şifresiz, mobil uyumlu İngilizce pratik uygulaması.

**Canlı hedef:** https://dmportal.com.tr/englishtutor

## Stack

- React 19 + Vite + TypeScript
- Base path: `/englishtutor/`

## Geliştirme

```bash
npm install
npm run dev
```

Uygulama `http://localhost:5173/englishtutor/` adresinde açılır.

## Build

```bash
npm run build
npm run preview
```

`dist/` çıktısı `/englishtutor/` altında sunulacak şekilde üretilir.
